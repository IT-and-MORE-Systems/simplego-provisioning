## Third-Party Software

### Rust crates

Every crate of the locked dependency tree (`Cargo.lock`) for the release
target `x86_64-unknown-linux-musl`. "In the binary": compiled into `sxprov`;
"build time only": build scripts and procedural macros, not shipped; "tests
only": development dependencies. Every licence is compatible with
AGPL-3.0-or-later (permissive licences; Apache-2.0 is compatible with version
3 of the GNU licences). The licence texts are in
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), which ships with every
release.

### Attestation agent (`agent/`)

The agent APK contains only its own code: no third-party library, no Kotlin
standard library. Its build uses:

| Component | License | Source |
|-----------|---------|--------|
| Gradle (wrapper `gradle-wrapper.jar`, `gradlew`, committed) | Apache-2.0 | https://github.com/gradle/gradle |
| Android Gradle Plugin (build only, not shipped) | Apache-2.0 | https://developer.android.com/build |
| Android SDK platform (compiled against, not shipped) | Android Software Development Kit License | https://developer.android.com/studio/terms |
