# Release Notes: v0.1.0-alpha

**Release Date:** November 26, 2026
**Previous Version:** none (first public version)
**Codename:** Proven Before Trusted
**Build:** 1 (`sxprov --version`: "SimpleGo Provisioning 0.1.0 alpha (build 1)")

---

## Highlights

- **Hardware attestation** - `verify` proves an untouched GrapheneOS with a locked bootloader: the chain up to Google's roots, Google's revocation list, and a verified boot key from the signature-checked GrapheneOS list.
- **Checked delivery** - `deliver` turns a GrapheneOS phone into a delivered SimpleGo phone in 15 checked steps, with a fleet record in the encrypted admin store.
- **Network lock before any install** - Orbot's always-on VPN with lockdown is proven at run time before the messenger, the F-Droid client or the SimpleX app is installed; Android's app link verifier is off, and the final check proves that nothing was verified.
- **The normal SimpleX app** - installed unchanged from SimpleX's own F-Droid repository, its signed index checked in pure Rust, updated later over Tor by the F-Droid client.
- **GrapheneOS** - status against the channel files, download with signature check, and `flash` with the official, unchanged `flash-all.sh`.
- **Activation files** - signed and encrypted `.sxact` activation and update files, with test vectors for the apps.

## Changes

### Delivery

| Detail | Value |
|:-------|:------|
| Messenger package | Taken from the messenger APK per delivery; optional `messenger_package` (fixed) and `messenger_package_pattern` |
| Activation provider | `messenger_provider_authority`, default `{package}.activation` |
| Installed messengers | Found by their activation provider, whatever their package name; a set-up one stops `deliver` and `flash` |
| Installed signers | Read from the pulled `base.apk` and checked against `dumpsys package`; the agent attests only |
| Record | Keeps the messenger package and `sxprov_version` (`0.1.0-alpha+1`) |

### Commands

| Command | Purpose |
|:--------|:--------|
| `--version` | Prints the product, version and build |
| `devices`, `verify` | Find the messenger by its activation provider; `--messenger-package PKG` names it explicitly |
| `deliver`, `undeliver`, `handover` | Delivery, undo on test phones, handover |
| `os status`, `os fetch`, `flash` | GrapheneOS |
| `activation issue`, `update`, `inspect`, `pubkey`; `store init`, `list` | Activation files and the admin store |
| `trust status`, `refresh`, `import`; `apk inspect`; `config show`, `set` | Trust material, APKs, settings |

## Upgrade Notes

First public version. Before using it with an existing config:

- `messenger_package` no longer has a default: leave it out (the package comes from the APK) or set it to fix one package.
- The agent package is now `dev.simplego.provisioning.agent`: rebuild the agent and set `agent_package` and `agent_apk`.
- The default GrapheneOS cache moved to `~/.cache/simplego-provisioning/grapheneos`.
- Records written by earlier builds stay readable; they have no `sxprov_version`.
